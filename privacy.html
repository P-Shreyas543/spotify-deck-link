Privacy

Short version: your data stays on your deck. Nobody runs a server for this project.

This website

  • A static page on GitHub Pages. It sets no cookies, has no analytics and loads no trackers.
  • When Spotify sends you back after login, this page reads the one-time login code from the address and forwards your browser to your deck on your home network. It does not store or send the code anywhere else.
  • GitHub may keep standard server logs (see GitHub's privacy statement).

The deck

  • Stores your Wi-Fi network name and password, your Spotify login token and your Spotify display name in its own flash memory, and nowhere else.
  • Talks only to Spotify (api.spotify.com, accounts.spotify.com, the Spotify image servers) over HTTPS, to show what is playing and send your playback commands.
  • Uses the Spotify permissions read currently playing, read playback state and modify playback state. It does not read your playlists, library or listening history.
  • Factory reset (Settings, or hold BOOT for 10 seconds) erases the Wi-Fi and Spotify data. You can also revoke access any time at spotify.com/account/apps.
